# AngularBlog

## Sobre

Esse é um **projeto simples de estudo** para criar a **estrutura visual** de um blog com Angular.

O meu objetivo com esse projeto é apenas me familiarizar com a sintaxe de componentes do Angular, por isso não tem nada realmente funcional (links, botões).
